    How to export from MuseScore
    1. Open the score in MuseScore. If it has other instruments, keep only the piano: File → Parts, or delete the other staves.
    2. Check the piano is one part with two staves (treble and bass). Two separate “right hand” / “left hand” parts are joined on import.
    3. File → Export…, choose Compressed MusicXML (*.mxl), and drop the file here.

    Repeats, first and second endings and pickup bars are written out on import. More in the import guide.

    Recognize a PDF (needs the local helper)

    PDF scores can be converted to notes on this computer with Audiveris, running as a local helper at 127.0.0.1:8937. Recognition takes minutes and makes mistakes — check the notes against the original.

    Imported scores are stored only in this browser. Find free scores at Mutopia or MuseScore (export as MusicXML).
